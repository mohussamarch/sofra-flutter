# مهمة: جمع وصفات عربية لسُفرة (لوكيل غير Claude)

كُتب 18 نوفمبر 2026. Claude سيراجع شغلك ويستورده للتطبيق بعدها. **أنت تكتب ملفات مرشّحين فقط ولا تلمس الكتالوج.**

## 1. المطلوب باختصار

اجمع وصفات عربية حقيقية من مصادر منشورة على الإنترنت، واكتب كل وصفة بالعربي بالشكل الموصوف في القسم 5، داخل مجلد مرشّحين جديد. اشتغل **بالترتيب** المكتوب في القسم 3، لا بشكل عشوائي.

## 2. كيف تُجمع الوصفات حاليًا (المسار الفعلي)

1. **البحث:** وكيل يبحث على الويب عن وصفة طبق محدد، ويفتح صفحة الوصفة في المصدر.
2. **الاستخراج:** يكتب الوصفة كملف JSON في `data/recipes/candidates-YYYYMMDD/<مجموعة>.json`، بالشكل `{collectedAt, collector, recipes: [...]}`. مثال كامل حقيقي: `data/recipes/candidates-20261026/egyptian.json`.
3. **الاستيراد (يقوم به Claude، لا أنت):** `node tool/recipes/import-candidates.mjs data/recipes/candidates-YYYYMMDD`
   - يتحقق من الشكل ويرفض الناقص.
   - يتخطى المكرر بنفس `id` أو نفس الاسم.
   - يرفض أي وصفة فيها خنزير أو كحول (`tool/recipes/hold-content.mjs`).
   - يضيف الوصفة إلى `recipes/data/<مطبخ>.json` و`recipes/data/index.json`.
   - يكتب تقريرًا في `import-report.json` بالمضاف والمتخطى وسبب التخطي.
4. **المراجعة:** Claude يراجع عينة مقابل المصدر، ثم يشغّل الاختبارات ويرفع على GitHub.

آخر دفعة بهذا المسار كانت 26 أكتوبر 2026: 65 مرشّحًا، أُضيف منها 5 فقط وتخطّى الباقي لأنه موجود فعلًا في الكتالوج. **لذلك راجع الموجود قبل أن تجمع** (القسم 4).

## 3. الترتيب المطلوب

قائمة مطابخ سُفرة المختارة (`docs/CUISINES-20261022.md`) تبدأ بالمطابخ العربية بهذا الترتيب. اعمل عليها بالترتيب نفسه:

| الترتيب | المطبخ | `cuisine` المقبول | الوصفات الفعّالة الآن |
|---:|---|---|---:|
| 1 | مصري | `مصري` | 30 |
| 2 | سعودي | `سعودي` | 16 |
| 3 | شامي | `شامي` أو `لبناني` أو `فلسطيني` أو `أردني` أو `سوري` | 28 |
| 4 | مغربي | `مغربي` | 13 |
| 5 | باقي المطابخ العربية | اسم البلد بالعربي، مثل `عراقي`، `يمني`، `إماراتي`، `كويتي`، `عُماني`، `تونسي`، `جزائري`، `ليبي`، `سوداني` | قليلة |

الأعداد من `recipes/data/index.json` يوم كتابة الملف. أعد عدّها بنفسك قبل البدء.

**طريقة الدُفعات:**

- **الدفعة الأولى:** 25 وصفة مصرية، ثم 25 سعودية، ثم 25 شامية، ثم 25 مغربية. كل مطبخ في ملف خاص به (`egyptian.json`، `saudi.json`، `levantine.json`، `moroccan.json`).
- **داخل كل مطبخ:** ابدأ بالأطباق البيتية الأشهر الناقصة، قبل أطباق المناسبات النادرة.
- **سد نقص أنواع الوجبات:** الموجود الآن في المطابخ الأربعة يغلب عليه الطبق الرئيسي (53 من 87 تقريبًا). الفطار 5 فقط، والشوربة 5، والحلويات 8، والسلطات 4. فوزّع كل 25 تقريبًا على: 10 أطباق رئيسية، و5 فطار، و4 حلويات، و3 شوربة، و3 سلطات أو مقبلات.
- **باقي المطابخ العربية مسموحة** (عراقي، يمني، خليجي، تونسي، جزائري، ليبي، سوداني، وغيرها)، لكن **بعد** الدفعة الأولى من الأربعة، وبقدر أقل منها. ضعها في ملف `arab-other.json`. التركيز يبقى على المصري والسعودي والشامي والمغربي.
- **لا تجمع أي وصفة من مطبخ غير عربي** (إيطالي، هندي، تركي، إلخ) في هذه المهمة.
- **إذا لم تكتمل 25** من مطبخ بعد بحث معقول، اكتب العدد الفعلي والسبب في تقريرك وانتقل للمطبخ التالي. لا تملأ النقص بوصفات ضعيفة.

## 4. قبل الجمع: تجنب المكرر

- اقرأ `recipes/data/index.json` (الحقل `recipes[].name` والحقل `cuisine`)، واقرأ ملف المطبخ نفسه في `recipes/data/` (مثل `egyptian.json`).
- لا تجمع طبقًا موجودًا بالاسم نفسه أو باسم قريب جدًا (مثل «فتة» و«فتة لحم»). الأطباق المصرية الموجودة الآن: كشري، ملوخية بالفراخ، مكرونة بالبشاميل، محشي، فتة، فول مدمس، طعمية، حواوشي، رز بلبن، بسبوسة، صيادية، عدس بالأرز والمعكرونة، بامية، شوربة عدس، فاصوليا خضراء، سلطة بلدي، بيض بالبسطرمة، كبدة إسكندراني، مسقعة، بيض مزغلل، بصارة، جلاش، كفتة جمبري، صينية بطاطس، بسلة بالجزر، غريبة، فطير مشلتت، وفتة الدجاج.
- طريقة مختلفة فعلًا لطبق موجود (مقادير أو تحضير مختلف) مسموحة، بشرط أن تكتب ذلك في `description` وتعطيها اسمًا يميزها.

## 5. شكل الوصفة (إلزامي)

```json
{
  "id": "eg-molokhia-bel-araneb",
  "name": "ملوخية بالأرانب",
  "nameEn": "Molokhia with Rabbit",
  "cuisine": "مصري",
  "category": "طبق رئيسي",
  "description": "جملة أو جملتان بالعربي تصف الطبق.",
  "servings": 4,
  "prepTime": 20,
  "cookTime": null,
  "totalTime": null,
  "difficulty": null,
  "ingredients": [
    {"id": "rabbit", "name": "أرنب مقطع", "amount": 1, "unit": "حبة"},
    {"id": "salt", "name": "ملح", "amount": null, "unit": null, "label": "حسب الرغبة", "scale": false},
    {"id": "coriander", "name": "كزبرة ناشفة", "amount": 1, "unit": "ملعقة صغيرة", "amountMax": 2, "note": "ملاحظة من المصدر"}
  ],
  "steps": [
    {"n": 1, "text": "خطوة بصياغتك.", "duration": 10},
    {"n": 2, "text": "خطوة تنتظر فيها.", "duration": null, "passive": true}
  ],
  "source": {"url": "https://...", "site": "اسم الموقع أو القناة", "title": "عنوان الصفحة في المصدر", "retrievedAt": "2026-11-18"}
}
```

| الحقل | القاعدة |
|---|---|
| `id` | حروف إنجليزية صغيرة وأرقام وشرطات فقط، ويبدأ بـ`eg-` أو `sa-` أو `lv-` أو `ma-`، أو `ar-` لباقي المطابخ العربية، وفريد |
| `servings` | عدد صحيح موجب **مذكور في المصدر**. إذا لم يذكره المصدر فلا تستخدم الوصفة |
| `amount` + `unit` | كما في المصدر. أي مقدار له رقم يحتاج وحدة. «حسب الرغبة» يُكتب `amount: null` مع `label` و`scale: false` |
| المدى (2 إلى 3) | `amount` = الأقل، و`amountMax` = الأعلى |
| الأوقات | بالدقائق ومن المصدر فقط. غير المذكور يبقى `null`، ولا تحسب `totalTime` بنفسك |
| `steps[].text` | **بصياغتك أنت بالعربي**، لا نسخ حرفي من المصدر |
| `category` | واحدة من: طبق رئيسي، فطار، حلويات، شوربة، سلطة، مقبلات، مخبوزات |
| `source.url` | رابط صفحة الوصفة نفسها، لا الصفحة الرئيسية |

## 6. المصادر

**أي موقع أو قناة مسموح**، بشرط أن تكون للوصفة صفحة كاملة فيها المقادير وعدد الحصص. لا توجد قائمة مواقع محددة. يُفضَّل الطهاة العرب المعاصرون المعروفون عند التساوي. أمثلة لمواقع سبق قبولها: `manalonline.com`، و`elwasfa.com`، و`sayidaty.net`، و`mawdoo3.com`، و`tasteofmaroc.com`.

**يوتيوب:** مسموح فقط إذا كان وصف الفيديو الرسمي نفسه فيه المقادير كاملة. سجّل رابط الفيديو، واكتب في `source.site` اسم القناة. لا تحمّل فيديو أو صوت أو صور، ولا تستنتج مقادير من مشاهدة الفيديو.

**ممنوع:**

- كتب الطبخ القديمة والتاريخية، وويكي الكتب (Wikibooks) بكل لغاته. هذا المسار موقوف بقرار المالك.
- اختراع وصفة، أو مقدار، أو وقت، أو عدد حصص، أو سعر، أو قيمة غذائية، أو قاعدة صحية.
- تخمين المطبخ من لغة المصدر أو من جنسية الطاهي. المطبخ يُكتب فقط إذا قاله المصدر أو كان الطبق معروفًا بوضوح أنه من هذا البلد.
- أي وصفة تحتاج خنزيرًا أو كحولًا (نبيذ، بيرة، ميرين، إلخ). خل النبيذ مسموح.
- التسجيل في مواقع، أو تجاوز حظر أو paywall، أو التواصل مع أي جهة.

## 7. حدودك في المستودع

- **تكتب فقط في:** `data/recipes/candidates-YYYYMMDD/` (مجلد جديد بتاريخ يوم العمل)، وملف تقريرك (القسم 8).
- **لا تعدّل:** `recipes/data/**`، و`lib/**`، و`test/**`، و`tool/**`، و`pubspec.yaml`. ولا تشغّل `import-candidates.mjs`.
- اقرأ `AGENTS.md` و`docs/STATUS.md` أولًا. اسحب `main` قبل البدء، واعمل commit وpush لملفاتك فقط عند الانتهاء.
- لا تكتب أي كلمة مرور أو مفتاح أو token في أي ملف.

## 8. التسليم

ملف `data/recipes/candidates-YYYYMMDD/REPORT.md`، فيه:

1. عدد الوصفات لكل مطبخ ولكل `category`.
2. الأطباق التي بحثت عنها ولم تجد لها مصدرًا صالحًا، مع السبب (لا عدد حصص، أو لا مقادير، أو مكررة، إلخ).
3. عدد الصفحات التي فتحتها وعدد عمليات البحث.
4. أي وصفة شككت فيها (مطبخ غير واضح، مقادير ناقصة) مع رابطها.

تحقق سريع قبل التسليم: كل ملف JSON صالح، ولا `id` مكرر بين الملفات، ولا وصفة بدون `source.url` أو `servings`. Claude سيشغّل المستورد ويرفض ما يخالف الشكل، ويراجع عينة يدويًا مقابل المصدر.
