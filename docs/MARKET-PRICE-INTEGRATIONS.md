# أسعار السوق والمتاجر — التنفيذ أولًا

14 أكتوبر2026. قرار المستخدم: أسعار المتاجر وتطبيقات التوصيل هي المسار الرئيسي، والمصادر الحكومية مرجع مساعد بالتوازي. لا انتظار صدور جدول رسمي لإتاحة سعر المستخدم أو بدء تكامل متجر.

## ما ثبت من المصادر الرسمية

| المصدر | الإمكانية المثبتة | ما يلزم لسُفرة |
|---|---|---|
| [طلبات Partner API](https://developer.talabat.com/api-specifications) | قراءة كتالوج vendor محدد: SKU وباركود وسعر وحالة وحقول وزن؛ تصدير كتالوج أيضًا | صلاحية الشريك للمتجر/السلسلة، وتأكيد السماح بمشاركة البيانات مع سُفرة؛ ليس وصولًا تلقائيًا لكل المتاجر |
| [HungerStation](https://developer.hungerstation.com/en/documentation/catalog-api-use-cases) | API/SFTP لشركاء المتاجر؛ تفاصيل المصادر في retailer-integrations-sa-20261014.json | نفس فصل صلاحية المتجر عن ترخيص قراءة السوق كله |
| [سلة](https://docs.salla.dev/5394168e0) | قراءة منتجات المتجر بنطاق products.read | تفويض صاحب المتجر؛ تأكيد الفرع وخدمة المنطقة والأسعار |
| [زد](https://docs.zid.sa/retrieve-a-list-of-products) | قراءة منتجات متجر محدد بصلاحية products.read وStore-Id | تفويض المتجر، لا كتالوج كل متاجر زد |
| [Rabbit](https://www.rabbitmart.com/partners/) | شراكات بيع منتجات/مطاعم/إعلانات | نحتاج اتفاق بيانات أسعار؛ برنامج البائع وحده لا يثبت ذلك |
| [Breadfast](https://www.breadfast.com/) و[instashop مصر](https://instashop.com/en-eg) | منصات بيع غذاء فعلية | لم يُثبت API عام لقراءة الأسعار؛ نتحقق من إتاحة feed/شراكة بدل افتراض وجوده أو نفيه |

توثيق طلبات يتيح [SFTP](https://developer.talabat.com/en/documentation/catalog-sftp-overview) لإرسال ملفات من التاجر إلى المنصة؛ هذا ليس قناة لتنزيل أسعار السوق كله. تفاصيل مصر والسعودية محفوظة في ملفي retailer-integrations داخل data/prices/research مع الروابط والمجهول. لم نراسل أي شركة أو ننشئ حسابًا أو نستخدم بيانات دخول.

## المسار المقترح القابل للتنفيذ

1. تجربة متجر بقالة/سوبرماركت متعاون في كل بلد. مصدره ملف POS/CSV/JSON مصرح بمشاركته، أو قراءة سلة/زد/كتالوج الشريك. اقتراح التجربة لا يعني أن عندنا اتفاقًا مع متجر بالفعل.
2. ربط كل مشاهدة بالبلد والمدينة والفرع وSKU/باركود وحجم العبوة وحالة العرض والضريبة/الرسوم والتاريخ. نحتفظ بسعر الفرع، لا نحوله إلى متوسط مصر/السعودية.
3. البدء بقراءة فقط؛ تحديث حسب اتفاق المصدر، وعرض آخر وقت تحقق. سعر المنتج منفصل عن رسوم التوصيل والخدمة وأي اشتراك. ثمن الكيلو لا يستنتج من متوسط وزن الحبة.
4. مع المنصة الكبيرة نطلب صراحة catalog-read/data licensing/affiliate feed، والفروع المسموحة وحق العرض ومدة التخزين والتحديث وحدود الطلبات. API الطلبات أو حساب المستهلك لا يثبت هذه الصلاحيات.
5. سعر المستخدم له الأولوية، ثم متوسط مشاهدات متوافقة ومراجعة. المجهول لا يصير صفرًا؛ التاريخ المؤكد لا يعاد تسعيره. لا استبدال تلقائي لخطة المستخدم.

## ما اتبنى الآن

`tool/prices/partner-catalog-candidates.mjs`: قارئ محلي لشكل رد GET كتالوج طلبات الموثق، بلا اتصال شبكة أو مفاتيح. يستقبل بلدًا/عملة/مدينة/متجرًا وchain/vendor ودليل الرد وبصمته، ويخرج مرشحات تحفظ السعر والباركود والوزن الأصلي. active=true لا يثبت المخزون، وتاريخ الجلب لا يصبح تاريخ السعر، وحجم العبوة/الهوية/العروض/حقوق النشر تبقى غير معتمدة. يرفض SKU المكرر والأسعار غير الصحيحة والسياق الناقص ونسب التضخم؛ الصفحة الواحدة لا تدعي كتالوجًا كاملًا.8اختبارات نجحت. هذا تجهيز استيراد، وليس ربطًا حيًا أو موافقة بيانات.

## المسار الحكومي المساعد

حُفظ جدول GASTAT الأصلي خارجيًا ببصمته، واستخراج خلايا جدول الغذاء في official/gastat-jul2026:100سطر رقمي للفترة يوليو2026 مع أعمدة الأشهر السابقة ونسب تغير منفصلة. لم يثبت أنه أحدث جدول؛ عملة جدول الغذاء تحتاج دليلًا أوضح، ولم يبن بنك أسعار تشغيلي منه. صفحة API المسماة متوسطات الأسعار عرضت نسب تغير CPI؛ الحارس يرفض معاملتها كسعر نقدي. سياسة الموقع عُرضت بالمتصفح وتذكر إعادة الاستخدام مع الإسناد وتوضيح التعديل والاستثناءات؛ لا اعتماد استثناءات البيانات آليًا. هذا مسار مساعد لا يسبق تجربة السوق.

الخطوة التالية المحددة: تجهيز عينة feed مصرح بها من متجر فعلي (متجر/فرع و20–50سلعة تشمل منتجات معلبة وخضار ولحوم)، ثم مراجعة هوية العبوات والتاريخ والحقوق واختبار الاستيراد. الوصول الحي يتطلب موافقة المصدر وتفويضه؛ لم يتحقق بعد.

## فحص ملف المصدر قبل القراءة

`readTalabatCatalogSnapshot(body, context)` يفحص SHA256 للبايتات الأصلية قبل فك UTF8 وقراءةJSON، ثم يمررها لنفس قارئ المرشحات. اختلاف سطرLF/CRLF أو تعديل السعر يرفض؛ UTF8/JSON غير صالح يرفض حتى لو طابقت البصمة. `talabatCatalogCandidates` وحده قارئ شكل بيانات غير معتمد، وليس بديلًا عن فحص المصدر. لا موافقة نشر أو صلاحية متجر أو ترقية أسعار بمجرد نجاح البصمة.20اختبار أسعار مرتبطة نجحت (10قارئ/7مقارنة/3نطاقات).
