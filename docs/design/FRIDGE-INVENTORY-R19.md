# r19 — حجرات مستقلة ومخزون بأرفف قابلة للتمرير

طلب المستخدم25أكتوبر: فصل حركة التلاجة والفريزر، تقريب الكاميرا وإزالة الجزء الأسود يمينًا، داخل غير مقيد بعدد أرفف واقعي مع تمرير لأعلى/أسفل وفئات قابلة للطي والتصفية، وتجربة مستقلة للتلاجة الحديثة البابين. زجاج البوتجاز المفتوح يكمل مساحة المسطح.

## حدود التنفيذ
Codex يعدل الفيجوال والأصول ومعاينة HTML فقط. Claude يملك الكود والعقد والمخزون الفعلي. هذه متابعة للحركة الموجودة، وليست اعتمادًا لمحرك ألعاب أو ترحيلًا للتطبيق.3ملفاتBlender فقط، ولا تعديلFirebase أوفوترة.

## الدخول إلى الحجرة
- أربعة مسارات: كلاسيك/تلاجة، كلاسيك/فريزر، حديثة/تلاجة، حديثة/فريزر. يفتح الباب المطلوب وحده وتبقى الحجرة الأخرى مقفولة. الحديثة: الفريزر يسارًا والثلاجة يمينًا.
- التصوير ينتهي أقرب إلى داخل الحجرة وبمنظور أمامي؛لا أجزاء من حواف الغرفة السوداء. الحركة للتلاجة المعنية فقط بـRGBA، فيما يبقى المطبخ إطارًا خلفيًا يتلاشى عند الدخول. لا إعادة رندر لكل تركيبة ألوان/سجادة/طاولة.
- الأضواء الثلاثة لكل مسار. بداية الحركة تسجل إحداثياتها بالنسبة للصورة الأساسية، وطبقة المطبخ الحالية يمكن أن تكون أي تركيب يختاره المستخدم. يظل أثر الضوء والانعكاس مسجلًا بالستايل الأساسي؛ليس هذا محرك انعكاسات آنيًا لكل تخصيص.
- بعد الفتح انتقال قصير إلى داخل مرن بارتفاع افتراضي. الأرفف والمحتويات تتحرك معًا في قائمة قابلة للتمرير، وليست أيقونات تمر فوق3أرفف ثابتة في الفيديو. لا خبز للمكونات أو الفئات داخل الرندر.

## التنظيم المقترح
تصنيف غذائي واحد لكل عنصر، مع موقع تخزين مستقل `fridge` أو`freezer`، وحالة إضافية مثل `leftover` أو`opened`. لا تعاد ملكية المخزون عند تبديل موديل الجهاز. النقل بين الحجرتين إجراء بيانات مستقل عندClaude.

- «بواقي الأكل» عرض حالة عبر الفئات، فلا تنسخ طبقًا مرتين ليظهر في قسمين. كل نوعي الجهاز يستخدمان نفس المعرفات؛التلاجة والفريزر يحتفظان بمخزونين مستقلين.
- شريط فئات باختيار متعدد،بحث،طي كل فئة وفتحها،وفتح/طي الكل. حالة الطي والتصفية لكل حجرة مستقلة. الفئة غير المعروفة تظهر فيمتنوع،ولا يُختلق تصنيف يقيني تلقائيًا.
- بيانات المعاينة تجريبية ومعلنة،وليست مخزون المستخدم. لا اختلاق كميات أو أسعار أو تغذية أو تواريخ صلاحية. قواعد الصلاحية والحفظ الصحي ليست ضمن هذا التصميم.

## تجربة مرئية قابلة للفحص
دخول كل حجرة وخروجها مستقلان،ومحتويات التمرير لا تغيّر الفيديو. يمكن تصفية أكثر من فئة،وطي صفوفها،ومشاهدة فئات أسفل الشاشة. تغيير الجهاز لا يمحو بيانات التجربة. النتيجة مراجعة بصرية وليستAPK أو اعتمادًا جماليًا نهائيًا.
