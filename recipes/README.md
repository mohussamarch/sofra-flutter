# دفتر وصفات سفرة 🍲

دفتر بيانات وصفات جاهز للربط ببرنامج **سفرة**. كل وصفة فيها مقادير وطريقة وعدد أشخاص وأوقات لكل خطوة،
بحيث البرنامج يقدر **يظبط المقادير أوتوماتيك** لما المستخدم يغيّر عدد الأشخاص، ويعرض **وقت كل خطوة**.

## المطابخ المتوفرة

| المطبخ | الملف | عدد الوصفات |
|---|---|---|
| مصري | `data/egyptian.json` | ١٢ |
| شامي | `data/levantine.json` | ١٤ |
| سعودي | `data/saudi.json` | ١٤ |
| إيطالي | `data/italian.json` | ١٤ |

> الإجمالي: **٥٤ وصفة** — الفهرس في `data/index.json`.

## السكيما الكاملة

### ملف المطبخ

```json
{
  "cuisine": "مصري",
  "cuisineSlug": "egyptian",
  "version": "1.0.0",
  "recipes": []
}
```

### وصفة واحدة

```json
{
  "id": "eg-koshari",
  "name": "كشري",
  "nameEn": "Koshari",
  "cuisine": "مصري",
  "category": "طبق رئيسي",
  "description": "جملة واحدة تظهر في الكارت",
  "servings": 4,
  "prepTime": 20,
  "cookTime": 45,
  "totalTime": 65,
  "difficulty": "متوسط",
  "ingredients": [],
  "steps": [],
  "tags": ["شارع مصري", "نباتي"],
  "notes": "ملاحظة أو بديل عملي"
}
```

| الحقل | النوع | ملاحظات |
|---|---|---|
| `id` | نص | فريد على مستوى كل الدفتر، بادئة المطبخ: `eg-` `sh-` `sa-` `it-` |
| `servings` | رقم | عدد الأشخاص اللي المقادير متكتوبة عليهم (الأساس) |
| `prepTime` / `cookTime` | رقم | بالدقائق |
| `totalTime` | رقم | **لازم** يساوي `prepTime + cookTime` (المدقّق بيرفض غير كده) |
| `difficulty` | نص | `سهل` أو `متوسط` أو `متقدم` |
| `category` | نص | `طبق رئيسي` `مقبلات` `شوربة` `فطار` `سلطة` `مخبوزات` `حلويات` `مشروبات` |

### مكوّن

```json
{ "id": "tomato-paste", "name": "صلصة طماطم مركزة", "amount": 3, "unit": "ملعقة كبيرة" }
{ "id": "salt", "name": "ملح", "amount": null, "unit": null, "label": "حسب الرغبة", "scale": false }
{ "id": "baking-soda", "name": "بيكنج صودا", "amount": 1, "unit": "ملعقة صغيرة", "scale": false, "note": "تُضاف قبل التحمير مباشرة" }
{ "id": "oil", "name": "زيت للتحمير", "amount": 2, "unit": "كوب", "note": "يُصفّى ويُعاد استخدامه" }
```

القواعد اللي بتخلي تعديل المقادير يشتغل صح:

1. **`amount` رقم دايمًا** لما يكون فيه كمية مقاسة. ممنوع `"1/2"` أو `"نص كوب"`؛ اكتب `0.5`.
2. **`amount: null`** معناها «مش كمية مقاسة» (ملح، فلفل، بهارات) ولازم معاها `"scale": false` ويفضّل `"label": "حسب الرغبة"`.
3. **`"scale": false`** لما الكمية **مينفعش تتبع عدد الأشخاص**:
   - بيكنج بودر / بيكنج صودا / خميرة (مواد رفع كيميائية)
   - زيت التحمير الغزير
   - مية العجن أو السلق التقريبية
   - فرخة كاملة أو بصلة بتُسلق لعمل شوربة
   وحط دايمًا `note` توضّح السبب.
4. **`optional: true`** للمكونات الاختيارية، و**`display`** لو عايز نص جاهز يظهر زي ما هو.

### خطوة

```json
{
  "n": 1,
  "text": "انقع العدس في ماء ساخن ١٠ دقائق، ثم اسلقه حتى يقرب من الاستواء.",
  "duration": 20,
  "passive": true,
  "tip": "لا تملّح ماء العدس من أول الأمر."
}
```

- `n` متسلسل من ١ بدون فراغات.
- `duration` بالدقائق، و**بتتعدّل مع عدد الأشخاص** زي المقادير.
- `passive: true` للخطوات اللي بتشتغل لوحدها من غير تدخّل: الفرن، التبريد، النقع، التخمير، راحة العجين.
  الخطوات دي هي اللي بتخلي **الوقت الكلي ≠ مجموع الخطوات**، والمدقّق بيحسبها صح.

### قاعدة أوقات الانتظار (مهمة)

في المطبخ فيه نوعين من الانتظار، والفرق بينهم مهم جدًا للحساب:

| النوع | مثال | التحضير الصح |
|---|---|---|
| انتظار **جوه وقت الطبخ** | الفرن ٣٠ دقيقة، التبريد ساعتين، تخمير العجين ساعة، طهي الأرز ٢٠ دقيقة | `"duration": 30, "passive": true` |
| انتظار **بره وقت الطبخ** | نقع الفول أو الحمص ليلة كاملة، تتبيل اللحمة ليلة كاملة، تجميد | `"duration": 0` والوقت الحقيقي مكتوب في نص الخطوة، ومن غير `passive` |

ليه؟ لأن **الوقت الكلي للوصفة** بيقيس من أول ما تبدأ لحد ما الأكل يبقى جاهز على السفرة.
نقع ليلة كاملة مش جزء من الجلسة دي، ولو حطيت `duration: 420` هتلخبط كل حسابات الوقت.

المدقّق بيتأكد إن **أطول خطوة انتظار** مش أطول من الوقت الكلي، وبيحذّر لو الوقت الكلي أقل بكتير
من الحد الأدنى المحسوب من الخطوات.

## تعديل المقادير حسب عدد الأشخاص

الدالة الأساسية: `scaleRecipe(recipe, targetServings)` من `src/scale.ts`.

```ts
import { scaleRecipe } from './recipes/src/scale';
import koshari from './recipes/data/egyptian.json'; // أو الوصفة المفردة

const للثمانية = scaleRecipe(koshari.recipes[0], 8);

للثمانية.factor;                        // 2
للثمانية.ingredients[0].display;        // "3 كوب"
للثمانية.ingredients[1].display;        // "2 كوب"
للثمانية.steps[0].duration;             // 28 دقيقة بدل 20
للثمانية.totalTime;                     // 90 دقيقة
```

### اللي بيحصل جوه

| الحالة | السلوك |
|---|---|
| كمية رقم + `scale` مش false | تتضرب في المعامل (الطلب ÷ الأساس) |
| `amount: null` أو `scale: false` | تفضل زي ما هي |
| وحدة كوب/جرام/مل | التقريب لخمسة (11.25 كوب ← 10 أكواب) للمعاملات الكبيرة |
| ملعقة كبيرة/صغيرة | التقريب لأقرب ربع (0.4 ← ½) ومفيش أقل من ¼ ملعقة |
| حبة/فص/رغيف | التقريب لأنصاف (بصلة ونص مسموحة، ربع بصلة لأ) |
| الوقت | للزيادة: `المدة × √المعامل` — ساعة فرن لأربعة مش هتبقى ساعتين لتمانية |
| الخطوات | المدة بتتعدّل، ونص الخطوة زي ما هو |

### التقريب مش بيضرب التقسيم

لو المستخدم رجّع العدد للأساس تاني، بترجع المقادير الأصلية بالظبط لأن التقريب بيتحسب من الكمية الأصلية كل مرة.

## أوقات الخطوات

`src/steps.ts` فيه أدوات جاهزة:

```ts
import { stepSchedule, formatScheduleLine, totalActiveMinutes } from './recipes/src/steps';

const جدول = stepSchedule(scaledRecipe);   // لكل خطوة: بداية ونهاية ومدة
totalActiveMinutes(scaledRecipe);          // الوقت الفعلي اللي المستخدم واقف فيه
formatScheduleLine(جدول[0]);               // "١. ٠٠:٠٠ – ٢٠:٠٠ (٢٠ دقيقة) انقع العدس…"
جدول[1].passive;                           // true = خطوة انتظار (فرن/تبريد/تخمير)
جدول[2].outsideSession;                    // true = وقتها خارج الجلسة (نقع ليلة كاملة)
جدول[2].durationText;                      // "خارج الوقت" في الحالة دي
```

المؤقّت نفسه دوال نقيّة (بدون `setInterval`) عشان تستخدمها في أي إطار عمل:

```ts
import { createTimer, tickTimer, timerText, timerProgress } from './recipes/src/steps';

let timer = createTimer(recipe);        // ابدأ من أول خطوة
timer = tickTimer(recipe, timer, 1);    // كل ثانية
timerText(timer);                       // "12:30"
timerProgress(recipe, timer);           // 0.42 لشريط التقدّم
timer.finished;                         // خلصت الوصفة
```

## ربط سريع بالبرنامج

```ts
// 1) اقرأ الفهرس مرة واحدة (54 وصفة، حجم صغير)
import index from './recipes/data/index.json';

// 2) فلترة: كل الوصفات اللي فيها طماطم وصلصة طماطم من مطبخين
const نتيجة = index.recipes.filter((r) => r.cuisine === 'مصري' || r.cuisine === 'شامي');

// 3) لما المستخدم يفتح وصفة، حمّل ملف المطبخ بس
const ملف = (await import(`./recipes/data/${entry.file}`)).default;
const وصفة = ملف.recipes.find((r) => r.id === entry.id);

// 4) عدّل المقادير على عدد الأشخاص اللي المستخدم طلبه
const مضبوطة = scaleRecipe(وصفة, عددالأشخاص);

// 5) اعرض الخطوات بأوقاتها
stepSchedule(مضبوطة).forEach((خطوة) => {
  // خطوة.durationText، خطوة.text، خطوة.tip، خطوة.passive
});
```

> نصيحة: خلّي مفتاح الحفظ في قاعدة البيانات هو `id` الوصفة، لأن كل التعديلات بتتحسب لحظيًا من الملف ومش محتاجة تتخزن.

## إضافة وصفة جديدة

1. افتح ملف المطبخ المناسب وحط الوصفة في آخر مصفوفة `recipes` بنفس الترتيب أعلاه.
2. شغّل `node scripts/validate.mjs` لحد ما مفيش أخطاء.
3. شغّل `node scripts/build-index.mjs` لتحديث الفهرس.
4. لو المطبخ جديد: اعمل ملف `data/<slug>.json`، وأضف المطبخ في `scripts/validate.mjs` و`scripts/build-index.mjs` و`src/types.ts`.

## ملاحظات على الترميز

- كل الملفات UTF-8 من غير BOM.
- النصوص العربية بالأرقام العربية-الهندية (١٢٣) مقبولة في الشرح، لكن **`amount` دايمًا أرقام إنجليزية** (0.5، 2، 250).
- التسميات بالإنجليزي لحقول الكود (`amount`, `unit`) والعربي للنصوص اللي بتظهر للمستخدم.
