# Source-separated packaged food data

`openfoodfacts/` contains real public Open Food Facts records. This subset and its derived lookup/normalized files are an **ODbL1.0 database**, with individual contents under **DbCL1.0**. Contains information from [Open Food Facts](https://world.openfoodfacts.org), made available under the [Open Database License](https://opendatacommons.org/licenses/odbl/1-0/); [contents license](https://opendatacommons.org/licenses/dbcl/1-0/).

This notice applies to the source data subset, not private people/health/purchase data or unrelated source databases. No product photos are included. Preserve attribution when presenting or exporting these records. See `docs/PRODUCT-DATA.md` for source contracts, interpretation gaps, category coverage, exact reproduction/check commands and redistribution notes.

Read `openfoodfacts/manifest.json` for actual counts and hashes. This is a broad seed, not a claim of completeness, current stock availability, verified popularity, verified labels or prices. Nutrition basis requires explicit label review; missing allergens/nutrients remain unknown. Products in the baby category are not feeding advice.
